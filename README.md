## 🌐 Sistema Multilingüe

El portfolio soporta dos idiomas:
- **Español** (idioma por defecto)
- **English** 

Características del sistema de idiomas:
- Cambio instantáneo sin recargar la página
- Detección automática del idioma del navegador
- Preferencias guardadas en Local Storage
- Traducción completa de todos los textos
